Welcome to the ComplianceGenie Agent installer

This installs a small background service that checks this Mac's security settings (disk encryption, firewall, OS updates, antivirus) and reports them to your organisation's ComplianceGenie portal.

Before you start Copy your enrollment token from the ComplianceGenie portal. The installer will ask you to paste it near the end. Tokens are valid for 7 days.
What the agent does not collect
  • File contents, documents, or emails
  • Browsing history, keystrokes, or messages
It reads only security-related system settings.

You'll be asked for your Mac password to allow the installation. That's normal.
